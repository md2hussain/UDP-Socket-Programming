# UDP Socket Programming

This project demonstrates basic UDP socket programming using Node.js. A simple UDP server is set up to listen for incoming messages on a specific port. Communication with the server is done using `ncat` to send UDP messages.

## Features

- Simple UDP server written in Node.js using the `dgram` module.
- Communication is tested using `ncat` (Netcat) for sending UDP messages.
- Server listens on `127.0.0.1` (localhost) by default on port `5500`.

## Prerequisites

- Node.js installed on your system.
- `ncat` (Netcat) installed to send messages to the server.
